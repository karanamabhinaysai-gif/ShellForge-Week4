# ShellForge

## Week 4 Features

- Process creation using fork()
- Command execution using execvp()
- Parent-child synchronization using waitpid()
- Error handling using perror()

## Week 5 Features

- Built-in command support
- cd
- pwd
- help
- clear
- exit
- Environment variables

## Week 6 Features

- Signal handling
- SIGINT support
- SIGCHLD support
- Zombie cleanup
- Shell survives Ctrl+C
